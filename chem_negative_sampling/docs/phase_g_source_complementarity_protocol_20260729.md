# Phase G source-complementarity analysis protocol

The original universal semi-hard inverted-U claim is unsupported and remains
retired. Phase G instead asks whether source selection depends on reaction
context and whether individual sources add distinct information.

The analysis reports:

- source-selection proportions and entropy by dataset/backbone;
- source-selection dependence on reaction family;
- policy shifts between scenarios;
- associations of gate probability with FNR, similarity, boundary closeness,
  OOF hardness and reward;
- leave-one-learned and leave-one-shuffled source ablations where available.

Development runs are always labelled
`EXPLORATORY_SOURCE_COMPLEMENTARITY_ONLY`. Even a sealed external run provides
confirmatory association, not causal mechanism evidence. The Phase G mechanism
Exit Criterion still requires a matched source intervention, held-out
replication, uncertainty intervals and competing-explanation ablations.
